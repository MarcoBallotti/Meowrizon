# Dati locali

- `rasters/`: raster e modelli del terreno.
- `kernels/`: kernel NASA/JPL per SPICE.
- `cache/`: risultati intermedi rigenerabili.
- `scenarios/`: file degli scenari.
- `sqlite/`: database SQLite.

Il contenuto di queste cartelle è escluso da Git. Non sono ancora inclusi dataset o kernel: i manifest con fonti, versioni e checksum verranno aggiunti insieme ai dati scientifici.
