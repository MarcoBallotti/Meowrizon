# Root catalog data

There is no database. Runtime contents are ignored by Git.

- `sources/`: original catalog downloads and `manifest.json` with URL, acquisition time, size and SHA-256.
- `regions/`: `regions.geojson` and `sites.geojson`, generated by `python -m app.cli init-regions`.
- `rasters/`: reserved terrain/raster storage.
- `cache/`: regenerable intermediate data.
- `scenarios/`: reserved saved-scenario JSON storage.

Docker mounts this root directory at `/app/data`. Generic acquisition, HTTP scientific jobs and CLI analysis have separate directories under `backend/data/`; see the [backend storage guide](../backend/README.md#storage-for-analysis). Directory names do not imply that regional grids or saved-scenario features have been implemented.
